# VoiceLab — Judge Demo Script

## Target Duration

**~2 minutes**

## 0:00–0:15 — Problem

Say:

> “Most voice agents can talk. But if I ask one a scientific question, I still need to trust the generated answer. VoiceLab connects voice interaction to deterministic scientific computation and verification.”

## 0:15–0:30 — Voice Input

Say:

> “I’ll give VoiceLab a molecular-symmetry problem using only my voice.”

Speak:

> **“Analyze BF₃ and tell me its point group.”**

## 0:30–1:00 — Scientific Result

Highlight:

```text
Point Group: D₃h
Operations: 12
Verification: 12 / 12 PASS
```

Say:

> “The agent didn't just generate D₃h as text. The scientific pipeline generated the symmetry operations and checked them against the molecular geometry.”

## 1:00–1:25 — Group Theory

Show:

```text
Γ(x,y,z) = E′ + A₂″
```

Say:

> “VoiceLab then builds the Cartesian representation and reduces it using the point-group character table.”

## 1:25–1:45 — Research Replay

Open Research Replay.

Say:

> “Every important step is exposed as a research timeline: the request, analysis, operations, verification, representation, and final result.”

## 1:45–2:00 — Close

Say:

> “That's the difference between a voice chatbot and a scientific copilot. VoiceLab turns a spoken scientific intent into computation, verification, and an auditable result.”

## Backup Demo

If live voice input fails:

1. Use the prepared BF₃ analysis.
2. Show the 12 operations.
3. Show `12 / 12 PASS`.
4. Show `Γ(x,y,z) = E′ + A₂″`.
5. Open Research Replay.

Keep the focus on the scientific workflow rather than infrastructure.
